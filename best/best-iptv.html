How this table works

Every row on this page corresponds to a provider we're actively tracking. When a provider clears independent, hands-on testing, its score, starting price, and status update here automatically — the same data file feeds this table and that provider's individual review page, so the two can never drift out of sync.

We don't rank providers with no verified data ahead of ones with verified data by giving them an invented score. Until testing is complete, a provider sorts alphabetically within its category rather than by a guessed position — and the Rank column always reflects whatever sort you're currently viewing, not a fixed, permanent position.

Read the full breakdown of what we test and how we weight it on our methodology page.
